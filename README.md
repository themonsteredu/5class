# MOAKIT 5class · 삼국시대 탐구실

초등 5학년 AI·사회 융합 10차시 웹교재. 사용자 제공 AI-L.E.A.P 교육과정 10차시에 맞추고, culture_bosung의 수업 교재 / 학생 활동 / 교사 자료 분리와 단계별 큰 화면 방식을 참고했습니다.

## 실행

Node 20 이상, 외부 패키지 의존성 없음.

```sh
npm run dev   # localhost:5175
npm test
npm run build # dist 정적 파일
```

Vercel 설정은 `vercel.json`에 포함되어 있습니다. 배포는 정적 호스팅이며 서버 비밀키가 필요하지 않습니다.

## 구성

- `#home`: 10차시 목차
- `#lesson/1` ~ `#lesson/10`: 각 6화면, 총 60개 교재 화면 / 해설 공개 / 큰 글씨 / 전체화면
- `#activity/1` ~ `#activity/10`: 관찰 → 질문 → 조사표 → 분류 → 관계도 → 낱말 분석 → 전시 설계 → 해설 작성 → 상호 검증 → 발표·성찰
- `#library`: 비상 사회 5-2 교과서 연계 자료 15종 / 나라·생활 주제 필터 / 두 자료 비교 / 추가 탐구 4종
- `#museum`: 모둠 전시 관람과 HTML 다운로드 (보유한 사진·글꼴 포함, 교과서 사진은 온라인 원문 링크)
- `#teacher`: 40분 운영 흐름, 차시별 지도안, 10종 A4 활동지와 관찰 기준

## 저장과 공유

현재 기기의 localStorage (`moakit-5class-v1`)에 저장합니다. 다른 기기는 JSON 내보내기/가져오기로 이어서 작업합니다. 가져오기는 현재 기록을 교체하므로 확인 창이 표시됩니다. 학생 글은 화면과 관람용 HTML에서 이스케이프하고 출처 주소는 HTTPS만 허용합니다. 파일 크기·스키마·자료 수·참조를 검증합니다.

관람 HTML에 포함된 교과서 원문 사진 링크는 인터넷 연결이 필요합니다. 관람 HTML에는 최종 해설·자료 출처·관계도·낱말 해석만 포함합니다. 확인 전 AI 초안, 성찰, 피드백 등 비공개 작업 기록은 포함하지 않습니다. 해설을 수정하면 해당 자료의 확인 표시가 해제됩니다.

실시간 학급 공유, 학생 계정, 허브 로그인 연동, AI API 자동 생성/분류는 구현 범위에 없습니다. 2·4·8차시는 교사 관리 AI의 실제 결과를 기록합니다. 낱말 분석은 사용자가 지정한 문자열의 중복 없는 등장 횟수이며 형태소 분석 또는 AI 분석으로 표시하지 않습니다.

## 자료

사용자 기존 ai-history-ar 프로젝트의 실제 사진을 재사용했습니다. 역사 설명 출처와 사진 출처는 개별 표시합니다. 선택한 자료의 수량으로 삼국 전체의 유산 분포를 추론할 수 없습니다. 출처 사이트 연결은 기관 운영 상황에 따라 달라질 수 있으므로 교사 자료에서 사전 확인을 안내합니다.

사진별 저작자·라이선스는 `ASSETS.md`와 `data.js`를 참고하세요. 학생에게 보이는 사진은 원본 비율을 유지합니다.

## 비상 교과서 연계 개편

2022 개정 비상교육(설규주) 사회 5-2 원문 25~31쪽을 직접 확인했습니다. 교과서 전체를 복제하지 않고 수업용 설명·관찰 질문을 새로 작성했습니다. 각 자료의 원문 쪽수를 표시하고 공개 교과서 뷰어를 연결합니다. 새 자료 사진은 원문을 열거나 종이 교과서를 펼쳐 관찰하는 구성입니다. 기존 무령왕릉 사진은 교과서 내부 복원도와 다르다고 명시했습니다.

고구려·백제·신라·가야의 음식과 집 / 옷차림과 신분 / 옷차림과 놀이 / 종교와 믿음 / 기술과 교류를 다룹니다. 자료실 비교 결과는 기존 작업 파일과 함께 저장합니다. 금동대향로·첨성대·기존 벽화와 금관 사진은 추가 탐구로 구분하며 이전 작업의 ID를 유지합니다.

교과서: https://ibook.vivasam.com/CBS_iBook/10703/contents/index.html?skin=basic01

## 1차시 관찰 수업
1차시는 여섯 자료 살펴보기(6분) → 생활의 단서 찾기(8분) → 사진으로 모르는 것 함께 생각하기(7분) → 모둠 질문(8분) → 알아볼 방법(7분) → 질문 나누기(4분)로 이어집니다. 수산리 벽화, 백제 식기, 가야 집 모양 토기, 신라 토우, 가야 갑옷·투구, 미륵사지 석탑 복원 모습의 교과서 발췌 이미지를 제공합니다. 금관·무령왕릉은 1차시에 포함하지 않습니다.

함께 연습하는 화면에서 백제 식기를 두고 “수저와 그릇이 보인다 → 먹었던 음식은 보이지 않는다 → 어떤 음식을 먹었을까?”를 단계적으로 공개합니다. 모둠은 고른 자료로 돌아가 같은 방법으로 질문을 만듭니다. 알아볼 방법으로 교과서·박물관 설명·AI의 도움을 연결하고, AI는 찾아볼 낱말이나 쉬운 설명을 제안할 수 있을지 예상합니다.

기록은 A4 한 장의 종이 활동지에만 남깁니다: 본 것 두 가지, 모둠 질문 하나, 알아볼 방법 하나. 자료 선택과 예시 공개는 화면 표시용이며 학생 답안을 웹에 입력하거나 저장하지 않습니다. 이전 디지털 관찰 기록은 프로젝트 JSON과 기록 인쇄에서 유지합니다. 새 활동지는 다음 차시까지 보관합니다.

실시간 AI 호출은 없습니다. 실제 AI의 답을 비교하는 활동은 2차시입니다. 다른 차시의 일부 자료는 교과서 원문 링크를 사용합니다. 이미지 출처와 발췌 범위는 ASSETS.md에 기록했습니다.

1차시 활동지: `assets/worksheets/lesson-1.pdf` (A4, 1쪽). 수정 후 `python scripts/worksheet-lesson1.py`로 다시 생성할 수 있습니다. 생성에 PyMuPDF와 fontTools가 필요하며, 사이트 실행·빌드에는 필요하지 않습니다. 교재와 활동지는 같은 S-Core Dream 글꼴을 사용합니다.

## 2차시: 탐구 질문 정하기
1차시 질문 다시 보기(5분) → 비교 연습(6분) → 같은 질문의 실제 AI 답변 비교(10분) → 역사 자료로 확인(9분) → 모둠 질문 다듬기(7분) → 3차시 조사 준비(3분). 학생은 `assets/worksheets/lesson-2.pdf`에 짧게 기록합니다. `#lesson/2`와 `#activity/2`는 같은 종이 활동 기반 교재를 엽니다.

교사 관리 AI에서 대표 질문 하나에 실제 답변을 두 번 받아 상단 **AI 답변 준비**에 붙여 넣습니다. 질문·AI 이름과 날짜·답변 두 개·연계 자료를 `l2-teacher-*` 키로 기존 프로젝트에 보관합니다. 화면은 실제 API에 연결되지 않습니다. 실제 답변을 준비하지 않으면 사용 순서를 표시하고 답변을 지어내지 않습니다. 비교 연습용 두 문장은 실제 AI 답변이 아님을 명시합니다. 준비한 답변은 현재 기기에서만 보이며 학생 기기로 자동 공유되지 않습니다.

활동지 재생성: `python scripts/worksheet-lesson2.py`. 폰트·필요 라이브러리는 1차시 활동지와 같습니다.

## 2차시 검증 활동 개편
여섯 유물별 학습용 문장 3개를 교과서·공식 기관 자료로 검증합니다. 실시간 AI 답변을 가장하지 않습니다. 학생은 유물별 A4 활동지 한 장에 처음 생각, 확인한 자료, 찾은 근거, 최종 판단과 수정 문장을 기록합니다. `assets/worksheets/lesson-2.pdf`는 6종 묶음이며 선택 유물별 PDF도 제공합니다. 교사용 해설은 수업 헤더와 마지막 단계에서 별도로 엽니다. 외부 링크 중 기관 첫 화면은 검색어를 안내하며 자료 상세 링크로 표시하지 않습니다.

## 3차시: 출처 있는 조사표 만들기
2차시 선택 유물과 종이 검증 기록을 그대로 활용합니다. 기록 살피기(7분) → 더 조사하기(23분) → 모둠 자료 모으기(10분)의 세 화면입니다. 재료·특징·쓰임에서 이미 확인한 항목을 표시하고 부족한 정보만 교과서·공식 기관에서 찾아 근거 위치와 함께 정리합니다. 소개문 작성은 하지 않습니다. 유물별 인쇄 활동지는 같은 조사표 형식이며 이름·나라·시대가 미리 표시됩니다.
모둠 기록 담당자는 자료실에서 조사한 유물을 담고 `#research`에서 특징과 근거를 입력합니다. 기존 `project.records`를 사용하므로 4차시 분류와 이후 분석으로 이어지고 기존 기록을 덮어쓰지 않습니다.
