# Museum exhibit sprites

Created with the built-in image generation tool, 2026-10-21. Project output: `assets/museum/*.webp`.

`guide.webp`: photorealistic ivory ceramic museum robot, bronze trim, dark glass face, identical neutral robot for all hidden exhibits, full body, transparent background, no artifact/country clues.

Artifact prompt set (one call per source): isolate the exact referenced artifact on transparent background; preserve silhouette, proportions, patina and decorations; realistic dimensional museum lighting; remove photo background/floor/text; for paired photographs use front view only; retain rock for relief and base for architecture; no cartoon or invented features.
